# 競合サイト ローカルミラー

## 起動

```sh
python3 competition/serve.py
```

ブラウザで <http://localhost:8080/> を開くと入口一覧が表示されます。停止は Ctrl+C。

ポートが埋まっている場合:

```sh
lsof -ti tcp:8080-8086 | xargs kill
```

## ポート割り当て

各サイトのルート絶対パス（`/_next/...` など）を維持するため、サイトごとにポートを分けています。

| ポート | サイト | 入口 |
| --- | --- | --- |
| 8080 | ポータル | `/` |
| 8081 | ビルダーワーク | `/auth/registration/qualifications/` |
| 8082 | レバジョブ LP | `/lp/02/0/e/00/00/01/00` |
| 8083 | プレックスジョブ | `/533/sekou-kanri/construction-management-engineer_25_t2/` |
| 8084 | レバテックキャリア | `/member/input/` |
| 8085 | ビーバーズ | `/ip/1-1-P5-v7/` |
| 8086 | レバジョブ 入力フォーム | `/sekokanri/step/01/` 〜 `/06/`（パターン別） |

## 構成メモ

- **レバジョブ**は LP 本体（`lp.levjob.jp` / STUDIO 製）と入力フォーム
  （`entry.levjob.jp` / Next.js 製）が別ドメイン・別アプリで、LP が iframe で
  フォームを埋め込む構成です。8086 で見えるのは **LP 中央の入力フォーム部分そのもの**。
  `entry.levjob.jp` は CSP `frame-ancestors` で `127.0.0.1` からの埋め込みを拒否するため、
  フォームもローカルに保存し、LP 側の `https://entry.levjob.jp` を
  `http://127.0.0.1:8086` に書き換えています（詳細は次節）。
- **レバテックキャリア**は Next.js App Router。HTTrack のパス書き換えで
  ハイドレーションが壊れたため、絶対パスのままの HTML を再取得して差し替えています。
- **プレックスジョブ**は Nuxt SPA。ルートチャンク `_nuxt/ed1c411.js` が未取得で
  白画面になっていたため追加取得しました。
- **serve.py** は HTML に `charset=utf-8` を付けて配信します。ビルダーワークの HTML は
  `<meta charset>` を持たず HTTP ヘッダー依存のため、これが無いと文字化けします。
- 拡張子なし URL（`/terms` など）は `.html` へフォールバックします。

## レバジョブ: `/sekokanri/step/01` 〜 `/06` はステップ番号ではない

URL の数字は**フォーム入口のパターン番号（出し分け / AB テスト）**です。
どのパターンも中身は「STEP 1〜6」の 6 ステップで、違うのは **1 問目**だけ。
link.txt の LP が実際に読み込んでいるのは **`/step/05`** です。

| パターン | 1 問目 | 備考 |
| --- | --- | --- |
| 01 | 業務経験を教えてください | 資格ではなく経験から聞く唯一の型 |
| 02 | 保有資格を教えて下さい | ラベルが「保有資格」。資格名は 2 行表記、「その他の資格」自由入力あり |
| 03 | どんな資格をお持ちですか？ | 資格名 2 行表記、「その他の資格」自由入力あり |
| 04 | どんな資格をお持ちですか？ | 03 に `※資格不問の求人多数！` を足しただけ |
| 05 | どんな資格をお持ちですか？ | 文言整理版。`*` が質問の前、資格名 1 行表記、自由入力なし。**LP が使用** |
| 06 | どんな資格をお持ちですか？ | 05 と完全一致 |

## 制約

- 取得日: 2026-09-12
- フォーム送信、サーバー側セッション、外部 API は動作しません。
- レバジョブ入力フォームの都道府県・地域は `/api/graphql/` から取得するため、
  ローカルでは選択肢が空になります（画面構成と遷移の確認は可能）。
- ビルダーワークは資格入力ステップのみ。次ステップ
  (`/auth/registration/job_change_intention`) は実際に登録フォームを送信しないと
  取得できないため、意図的に未取得です。
- 各 LP は元のまま計測タグを読み込みます。オンラインだと競合側の解析・広告タグに
  通信するので、必要なら機内モードや `/etc/hosts` でブロックしてください。
