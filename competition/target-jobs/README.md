## 先に見えた傾向

- **最もフォームLP化が進んでいるのは整備士領域**。資格・転職時期などの非個人情報から始め、最後に連絡先を取る型が複数ある。
- **設備保守はメカワクが強い**。「整備・メンテナンス・エンジニア」と広く括り、設備保全、FA、プラント、昇降設備まで横断して求人の幅を訴求している。
- **ビルメンは資格起点が強い**。電気工事士、電験、ビル管、ボイラーなどを求人検索と登録理由の両方に使う。大手系列・高待遇求人の見せ方も多い。
- **製造は転職より仕事探しの即時性が強い**。高収入、寮、日勤、土日休み、未経験、履歴書不要を前面に出し、求人カードで具体的な月収を見せる。
- 4職種共通で使える型は、**答えやすい職種別設問 → 該当求人の期待 → 個人情報**。ただし最初の設問は共通化せず、職種ごとに変える余地が大きい。

## フォームへの落とし込み候補

| 職種 | 1問目の有力候補 | 次に見せる価値 |
| --- | --- | --- |
| ビルメン | 保有資格 | 資格を活かせる大手系列・高待遇求人 |
| 設備保守・メンテナンス | 直近扱っていた設備・機械 | 経験が転用できる別業界を含む求人 |
| 製造・技能職 | 希望する働き方、または経験工程 | 月収・休日・寮・勤務帯に合う求人 |
| 自動車整備士 | 保有資格 | ディーラー以外も含む年収・休日改善求人 |

## 判定ラベル

- **段階入力**: 1画面1問または少数項目で「次へ」を押して進むフォーム。
- **確認画面型**: 1画面に複数項目が並び、入力→確認→完了で進む通常フォーム。
- **一括フォーム**: LP下部などに全項目をまとめて表示するフォーム。
- **求人サイト型**: 求人検索・一覧が主で、LPとしては訴求や求人の見せ方を参考にするサイト。
